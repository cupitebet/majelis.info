## 🆘 Troubleshooting

### "Schema tab tidak ada di Yoast"

**Solution:**
```
1. Update Yoast SEO plugin ke versi terbaru
2. Dashboard → Plugins → Yoast SEO → Update
3. Atau: Yoast SEO → General → Features
   → Toggle "Advanced settings pages" ON
```

---

### "SEO score tidak berubah setelah edit"

**Solution:**
```
1. Click [Update] button lagi
2. Hard refresh page: Ctrl+Shift+R (Windows) / Cmd+Shift+R (Mac)
3. Clear cache: WP Rocket → Clear Cache
4. Wait 5 menit, refresh lagi
```

---

### "Rich Results Test shows errors"

**Solution:**
```
1. Check schema type sudah benar (FAQPage, HowTo, etc)
2. Clear WordPress cache
3. Clear Cloudflare cache (if using)
4. Test again after 10 menit
5. If still error: Copy error message, contact support
```
